Save this session. Follow the wiki handbook's Capture section, as for "save this session".

1. Look back over the whole conversation for what a later session would want and couldn't get from the code or its git history: decisions and their reasons, direction from the user, facts established or corrected, problems solved with cause and fix, research findings with sources. 3. Compile those wikis now, under their locks, and commit as the handbook's Sync section says.
4. If the user keeps a work journal (rules/journal.md), add one line per project for this session's work that left no commit: `wiki.sh journal note <project> "<what was done and how it ended>"`.
5. Report each note's path and the compile counts in a line or two.

If there is nothing worth keeping, say so and write nothing.
