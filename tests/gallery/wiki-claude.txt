My knowledge wikis live in <tmp>/wikis, one folder per project, plus a shared one at <tmp>/wikis/global. Wherever their handbooks say `wiki.sh`, run `<repo>/wiki.sh`. At session start, run `<repo>/wiki.sh start` in the repository you are working in. It names the wiki that covers it, pulls, and prints what to read first. Read that wiki's AGENTS.md and follow it. If no wiki covers the repository, read <tmp>/wikis/global/AGENTS.md and follow that, and create the repository's wiki with `<repo>/wiki.sh new <repository-name>` the first time you have something to file there. Outside any repository, use the shared wiki. If your tool can hand work to sub-agents on cheaper models, do it for large, self-contained work as <tmp>/wikis/delegation.md says, following <tmp>/wikis/global/rules/delegation.md.
